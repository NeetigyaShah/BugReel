# Mode-2 webhook dispatch is asymmetric by capability

Webhook targets are auto-detected by hostname and get different payloads. Discord (`discord.com/api/webhooks`) receives `multipart/form-data`: a rich embed plus `snapshot-annotated.png` and the `.bugpack` itself, with a 7.5MB size guardrail that falls back to a lite bugpack (JSON + images) when video pushes past it. Slack incoming webhooks (`hooks.slack.com`) are text-only by protocol — they reject multipart and CORS-preflight custom headers — so Slack receives a CORS-safe Block Kit message whose footer notes the `.bugpack` was downloaded locally instead. Custom/generic webhooks get `multipart/form-data` with `report` + `bugpack`. Slack media upload requires a bot token + `files.upload`; deliberately deferred as a Phase-2 adapter concern, not a Mode-2 hack.
